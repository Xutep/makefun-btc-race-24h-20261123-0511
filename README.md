A long-only trend-following bot that trades cbBTC/USDC on 1-minute on-chain bars: it buys in full when the 20-bar EMA rises above the 90-bar EMA and exits everything on a 2% trailing stop or a 1.5% hard stop, with a 60-bar cooldown after each exit.

## Run it
